# 缺省压缩阈值兼容

2026-09-26，在 DMIT 已部署接口上，Astra、Sol 的 `high` 最小请求均验证：只提供 `context_management: [{"type":"compaction"}]` 返回相同的上游 422；显式提供 `compact_threshold: 475000` 返回 200。475000 仅为对照值。

本地补丁仅对显式 compaction 的缺失/null 阈值补入可配置的 `default_compact_threshold`，默认 200000。已有明确值、未知策略及其他请求字段保持不变；没有策略时不注入压缩。历史日志没有保留原请求正文，不能据此断言所有 Invalid request body 都由缺少阈值导致。

验证入口：`go test -race -count=1 ./...`、`go vet ./...`。`context_management_test.go` 覆盖流式/非流式、原始请求/转换请求、缺失/null/显式阈值、配置覆盖、非法配置及源对象不变性。生产是否生效需读取已加载插件版本；本地构建完成不代表已部署。

本轮上述回归和 vet 均通过；默认补齐值 200000 的上游对照在 Astra、Sol 均返回 HTTP 200 / response.completed。另用合成 64×64 PNG 验证无图、单图、双图的 low 请求均返回 200，不能把其他带图 422 一概归因于图片数量。没有使用或记录用户原始图片。
